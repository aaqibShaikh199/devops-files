# DevOps Utilities

This repository contains various **DevOps-related scripts, configurations, and templates** that I use for automation, server setup, and cloud management.

---

## 📁 Repository Structure

- **Apache/**
  - `laravel.conf` – Apache virtual host configuration for Laravel apps

- **AWS/**
  - Shell scripts and IAM policies for managing AWS services  
  - Examples: EBS volume resize, S3 access policies, Lambda function, MFA enforcement

- **Nginx/**
  - Configuration files for React, Node.js, and WebSocket setups

- **shell-script/**
  - Useful Linux shell scripts for automation  
  - Examples: Docker & Minikube installation, user creation, database migration, EKS update

- **terraform/**
  - Infrastructure as Code example for AWS (security group configuration)

---

## 🧠 Purpose

A personal collection of ready-to-use **DevOps tools and examples** to:
- Automate common tasks  
- Store reusable scripts and configs  
- Standardize setups across environments
